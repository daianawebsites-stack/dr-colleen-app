1.7 Motion · click to slide

Click any track to slide the circle right. Click again to slide it back. All circles default to the left. Each uses its motion duration with the easing.smooth curve: cubic-bezier(0.4, 0, 0.2, 1). UI elements that use motion: input focus / blur, color & border transitions, modal fade-in, tooltip enter / exit, accordion expand / collapse, hover lifts, save link state changes.
